# Практикалық жұмыс №5 — REST API интерактивті прототипі

## Жоба және API

StudyPlan оқу тапсырмаларын басқарады. Серверлік бөлік ретінде оқу мақсатындағы [JSONPlaceholder Todos API](https://jsonplaceholder.typicode.com/) қолданылады. Негізгі URL: `https://jsonplaceholder.typicode.com`.

| Әдіс | Endpoint | Операция |
|---|---|---|
| GET | `/todos?userId=1&_limit=15` | Бірінші пайдаланушының тапсырмалар тізімін алу |
| GET | `/todos/{id}` | Бір тапсырманы алу (қосымша endpoint) |
| POST | `/todos` | Жаңа тапсырманы жіберу |
| PUT | `/todos/{id}` | Тапсырманы толық жаңарту (атауын өзгерту) |
| PATCH | `/todos/{id}` | Тапсырманың орындалу күйін өзгерту |
| DELETE | `/todos/{id}` | Тапсырманы жою |

HTTP сұраулары `http` кітапханасымен орындалады. `ApiClient` JSON кодтау/декодтауды, HTTP статусын тексеруді және 10 секундтық timeout-ты қамтамасыз етеді. `RemoteTodo` моделі JSON-ды Dart объектісіне түрлендіреді. `TodoApiService` endpoint-терді шақырады, `RemoteRepository` интерфейс күйін және жергілікті Hive деректерімен байланысты басқарады.

## Қолданбада көрсету және жергілікті дерек

Профиль бетіндегі **Сервер (API)** тармағын ашыңыз. Экран GET сұрауын бастап, тізімді көрсетеді. Құралдар:

- **+** — POST арқылы жаңа серверлік тапсырма қосу;
- қарындаш — PUT арқылы атауын өзгерту;
- құсбелгі — PATCH арқылы орындалу күйін ауыстыру;
- қоқыс шелегі — DELETE арқылы жою;
- жүктеу белгішесі — серверлік тапсырманы жергілікті қорға импорттау;
- **Серверге жіберу** — серверге синхрондалмаған жергілікті тапсырмаларды POST арқылы жіберу;
- жаңарту белгішесі — тізімді GET арқылы қайта алу.

Импортталған тапсырма `remoteId` арқылы сервер жазбасымен байланысады. PUT/PATCH өзгерістері сол жергілікті тапсырмаға да жазылады. Hive деректері қолданбаны қайта іске қосқанда сақталады.

## Сұрау күйлері және қателер

- GET кезінде `Loading` индикаторы, операциялар кезінде жоғарғы progress bar көрсетіледі.
- Сәтті жауаптан кейін тізім дереу жаңарып, хабарлама шығады.
- Интернетке қосылу қатесі, сервердің 4xx/5xx жауабы, қате JSON және timeout түсінікті мәтінмен көрсетіледі; GET қатесінде **Қайталау** батырмасы бар.
- HTTP және JSON exception-дары `ApiException` иерархиясына түрленеді.

## Қолмен тексеру

1. Сервер экранын ашып, GET нәтижесі мен жаңарту батырмасын тексеру.
2. **+** арқылы жазба қосып, тізімге қосылғанын тексеру (POST).
3. Атауын өзгертіп, жаңа атауды көру (PUT).
4. Құсбелгіні ауыстырып, күйінің өзгеруін көру (PATCH).
5. Жазбаны жойып, тізімнен кеткенін тексеру (DELETE).
6. Сервер жазбасын жергілікті қорға көшіріп, синхрондалмаған жергілікті тапсырманы серверге жіберіп көру.
7. Желіні өшіріп немесе баяулатып, Error/timeout күйін тексеру.

REST қабатының автоматты тексерістері `test/api_test.dart` ішінде GET, POST, PUT, PATCH, DELETE, server error, offline, timeout және қате JSON жағдайларын қамтиды.

## API шектеуі

JSONPlaceholder — демонстрациялық API: POST/PUT/PATCH/DELETE сұрауларына сәтті жауап береді, бірақ өзгерістерді тұрақты сақтамайды. Сондықтан экран сұрау жауабынан кейін жедел жаңарады, ал қайта GET жасағанда API-дың бастапқы деректері қайтуы мүмкін. Тұрақты серверлік сақтау үшін осы endpoint-терді нақты backend URL-ына ауыстыру керек.
